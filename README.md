 Kamalesh M — Portfolio

A responsive personal portfolio website made with HTML, CSS, and a small amount of JavaScript.

## Preview locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a repository on GitHub. For a personal site, name it `YOUR-GITHUB-kamalesh7864-max.github.io`.
2. Upload `index.html` to the repository's root and commit the changes.
3. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Wait for deployment and open the URL shown in the Pages settings.

## Personalize
- Update the skills section to list only skills you actually know.
- Replace the sample project cards with your real projects and links.
- Add a profile photo if you want one.
